## שלב 1 — מספר טלפון חדש (עכשיו)

### 1.1 לקנות מספר

אופציות נפוצות בישראל / לפיילוט:

| אפשרות | מתי מתאים | הערה |
|--------|-----------|------|
| **מספר ישראלי מספק סלולר / VoIP עסקי** | פיילוט אמיתי עם חנויות | חייב לקבל SMS לאימות Meta |
| **מספר בדיקה של Meta** (חינמי בממשק Developers) | רק בדיקת webhook מקומית / smoke | לא מספר "שלך" ללקוחות |
| **מספר בינלאומי (Twilio וכו')** | אם אין ישראלי זמין | Meta תומכת; וודא קבלת SMS |

**דרישה קריטית:** המספר חייב לקבל **SMS** (או שיחת אימות) כש־Meta מבקשת לאמת.

**לא מומלץ לפיילוט Optical Center:**
- מספר שכבר מחובר ל־WhatsApp אישי / Business App אחר
- מספר בלי SMS
- מספר שכבר בשימוש באפליקציית Meta אחרת בלי ניתוק

### 1.2 לפני שמחברים ל־Meta — צ׳קליסט

- [ ] המספר בידיים שלך (SIM / פאנל ספק)
- [ ] אתה יכול לקרוא SMS עכשיו
- [ ] אם היה WhatsApp על המספר — **נתקת** אותו מ־WhatsApp (הגדרות → חשבון → מחק / החלף מכשיר)  
  Meta לא תאפשר מספר שפעיל ב־WhatsApp רגיל בלי ניתוק
- [ ] רשמת את המספר בפורמט בינלאומי: `9725XXXXXXXX` (בלי `+` ו־`-`)

### 1.3 מה לשלוח לי כשסיימת שלב 1

רק את זה (בלי סודות):

1. האם קנית מספר ישראלי / אחר / משתמש במספר בדיקה של Meta?
2. המספר בפורמט `9725…` (או מדינה אחרת)
3. האם קיבלת SMS בהצלחה במבחן קצר (שלחת לעצמך)?
4. האם המספר **לא** מחובר כרגע ל־WhatsApp אישי?

## שלב 2 — Meta (אחרי שתאשר שלב 1)

בקצרה מה יבוא (בלי לעשות עכשיו):

1. Developers.facebook.com → אפליקציה (או קיימת)
2. הוספת מוצר **WhatsApp**
3. הוספת המספר ל־WhatsApp → API Setup
4. אימות ב־SMS
5. העתקת: Phone Number ID, Access Token, App Secret
